# QJC_website

A simple personal website built with Next.js and TypeScript.

## Sections

- Home
- Life
- Thoughts
- Work
- CV

## Development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

The first version intentionally keeps the design minimal, with restrained typography, generous spacing, and very little visual decoration so that content can be added gradually.
